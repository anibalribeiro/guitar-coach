Field Guide × Luthier's Bench

The teaching path from Field Guide, the warm physical workspace from Luthier's Bench, and one fewer column.

PATH 264WORKSPACE

Why two columns

The third column was doing two jobs: library and coach. Setup moves into the lesson header; the tuner and the real YouTube card move into the path rail. The workspace gets the board width back.

From Field Guide

  • The persistent path: tune → notes → shape → blues → power → changes.
  • Lesson copy that explains before it drills.
  • The real photo as a lesson hero, not a hidden disclosure.

From Luthier's Bench

  • Warm paper, wood board, brass points and copper actions.
  • Serif lesson title; compact utility type.
  • The board still feels like an instrument, not a diagram.

Materials

The photo, the local six-second clip and the JustinGuitar thumbnail are all visible above the board. The YouTube card is a real link; the image is saved locally.

Tradeoff

The path rail costs the workspace 264px. It works at 1280px because the board is 13 frets, not a full 20-fret neck. Below 1100px the path becomes a horizontal strip above the lesson.

This is the build: one path rail, one workspace, no third column. The real materials are part of the lesson, not an appendix.
← Compare the three directions

The decision

One path rail. One workspace. Nothing else.

The Field Guide path becomes the permanent left margin. The lesson, real reference, steps, board and transport share one warm workspace. Setup is a row, not a rail.

What moves

  1. Key, scale, position and labels become one setup row in the lesson header.
  2. The tuner and Watch & read card live in the path rail.
  3. The real photo and clip sit between the lesson title and the board.
  4. The board loses the library column and gains the width.

Next if approved

Rebuild the shell as a 264px path plus workspace; move setup into the lesson header; keep the drawer for the full library; then implement the Field Guide lesson copy and real-media card.
